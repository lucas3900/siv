# Simple Image/Video Viewer (SIV)

## Development
### Dependencies

#### Ray Lib
zig fetch --save git+https://github.com/raylib-zig/raylib-zig#devel

#### FFMPEG
sudo pacman -S ffmpeg

### Run
zig build run
zig build run -- ~/photos/test.png
